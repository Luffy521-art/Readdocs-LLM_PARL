**主要研究方向**

1. **奖励模型引导的知识蒸馏**  
   大模型负责提供高质量知识，奖励模型负责筛选、重加权或评价样本，小模型通过 SFT 和 PPO 学习。

2. **过程奖励引导的小模型优化**  
   研究 token-level、step-level 和序列级奖励，重点体现你当前 PARL 的特色。

3. **教师反馈驱动的在线强化学习蒸馏**  
   小模型不断生成答案，教师模型、API 或验证器提供反馈，PPO 根据反馈更新模型。

4. **可验证奖励驱动的训练**  
   用数学验证器、编译器、单元测试、JSON/XML 校验器或 SUMO 仿真器自动产生奖励，减少对人工和 API 评分的依赖。

5. **奖励模型蒸馏与轻量化**  
   用大模型或 API 训练小型 Reward Model，再由小型奖励模型指导学生模型训练，降低调用成本。

6. **参数高效的 PPO 与奖励蒸馏**  
   对比全参数 PPO、LoRA PPO、最后几层训练和分层冻结，研究小模型在有限显存下的优化效果。
